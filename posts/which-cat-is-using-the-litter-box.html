Day 4

  • Watch first. A quiet session near the box often solves it fastest, and stay relaxed because cats may wait if stared at.
  • Isolate if needed. A short test with one cat and one box gives a clean answer, then check clump size and timing to narrow the suspects.
  • Log it. One incident is not a pattern, so record it to see if it repeats, and consider a camera if watching is not possible.
